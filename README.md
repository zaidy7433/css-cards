# 🃏 CSS Cards

A simple and attractive **CSS Cards** project created using **HTML and CSS**.
This project demonstrates how to create and style cards for displaying content on a webpage.

## ✨ Features

* 🃏 Attractive card design
* 🎨 CSS styling
* 🖼️ Images in cards
* 📝 Content sections
* 🖱️ Hover effects
* 📐 Clean layout

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Live Website

https://zaidy7433.github.io/css-cards/

## 🎯 Purpose

This project was created to practice **HTML structure, CSS cards, layouts, spacing, images, and hover effects**.
